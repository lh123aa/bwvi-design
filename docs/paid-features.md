# BWVI 付费功能规划

> 创建日期: 2026-05-06
> 状态: 规划中（待开发）
> 许可证说明: BWVI CLI 保持 Apache-2.0 开源，付费功能为云端增值服务

---

## 核心理念

```
开源 CLI = 增长引擎（永远免费）
付费服务 = 增值体验（云端 + 协作 + 规模化）
```

- CLI 25 个命令、115 品牌、56 风格、50+ 蓝图、设备边框、评审体系 → **永远免费**
- 付费功能通过 `--engine=cloud`、`bwvi cloud` 等命令调用云端 API → **收服务费而非代码费**

## 付费功能详细清单

### 🥇 Tier 1 — 个人专业版 ($9-19/mo)

#### 1. 云端设计指纹

| 项目 | 说明 |
|------|------|
| **当前免费状态** | 本地 `.bwvi/fingerprint.yaml`，单机可用 |
| **付费升级** | 云端同步：登录 bwvi cloud → 自动备份指纹 → 跨设备共享 |
| **额外功能** | 设计风格趋势仪表盘（可视化用户偏好演化） |
| **技术方案** | REST API + SQLite/PostgreSQL，CLI `bwvi cloud sync` |
| **优先级** | P2 |

#### 2. 云端品牌库 (500+)

| 项目 | 说明 |
|------|------|
| **当前免费状态** | 115 个静态品牌，源码内嵌，版本更新需升级 npm |
| **付费升级** | 500+ 品牌云端托管，品牌 rebrand 自动同步，品牌合规监控报告 |
| **额外功能** | 品牌色板合规扫描：`bwvi critique --brand-compliance` |
| **技术方案** | CDN 分发品牌 JSON，每周自动抓取更新 |
| **优先级** | P2 |

#### 3. 云生成引擎

| 项目 | 说明 |
|------|------|
| **当前免费状态** | `--direct` 本地内置生成（质量 ★★★☆☆） |
| | `--engine=od/huashu` 需用户自己搭建环境 |
| **付费升级** | `--engine=cloud` 一键调用云端 GPT-4/Claude，3-5s 返回高质 HTML |
| **交互模式** | `bwvi generate "..." --engine=cloud --interactive` 支持流式对话 |
| **技术方案** | CLI →  REST API → LLM → HTML 返回 |
| **计费** | 按月费配额（如 100 次/月）或按次（$0.1/次） |
| **优先级** | **P0（核心卖点）** |

#### 4. AI 生图内置配额

| 项目 | 说明 |

```
CLI (开源, Apache-2.0)                 云端 (专有)
┌─────────────────────┐        ┌──────────────────────┐
│ bwvi generate       │ ──→   │ Cloud API Gateway    │
│ bwvi critique       │   ↑   ├──────────────────────┤
│ bwvi analyze        │   │   │ 用户服务 (Auth/Bill) │
│ bwvi cloud (new)    │ ──┘   ├──────────────────────┤
│                     │       │ 生成引擎 (LLM queue)  │
│ bwvi ci-check (new) │ ──→   ├──────────────────────┤
│ bwvi --engine=cloud │ ──→   │ 品牌库 (500+ CDN)    │
└─────────────────────┘       ├──────────────────────┤
                              │ 指纹同步 (Postgres)  │
                              ├──────────────────────┤

                              └──────────────────────┘
```

## 风险控制

| 风险 | 等级 | 缓解措施 |
|------|:----:|----------|
| 社区 fork 付费功能 | 低 | 付费是云端服务，fork 无法复制 |
| 用户反感"开源转付费" | 中 | CLI 永远免费，付费是额外增值，非削减现有功能 |
| 云服务成本过高 | 中 | LLM 按需付费 + 缓存 + 批次处理 |
| 竞品免费功能覆盖 | 低 | BWVI 决策链 + 评审体系是独有护城河 |
| GitHub 社区反应 | 低 | 遵循 Supabase/Cal.com 模式，已有大量成功先例 |

## 原则清单

1. **CLI 永远免费** — 25 个命令、115 品牌、56 风格、50+ 蓝图、评审体系绝不收费
2. **付费 = 云服务，非代码锁定** — 不在 CLI 中硬编码业务逻辑到付费墙
3. **清晰的许可证边界** — Apache-2.0 覆盖 CLI 代码，云端服务单独 EULA
4. **先价值后收费** — 让用户先用 CLI 体验到 200ms 产出的价值，再引导到付费
5. **开源是获客引擎，不是慈善** — 每个免费用户都是潜在付费用户
