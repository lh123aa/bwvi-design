# 图片规范

## 图片比例

| 用途 | 比例 | 说明 |
|:----|:----:|:-----|
| Hero 大图 | 16:9 / 21:9 | 全屏宽，裁剪居中 |
| 卡片封面 | 4:3 / 3:2 | 统一裁剪，视觉对齐 |
| 产品展示 | 1:1 / 4:5 | 电商风格，白底优先 |
| 头像 | 1:1 | 圆形裁剪，最小 80x80 |
| 图标 | 1:1 | SVG 最优，PNG 备选 |

## 占位图策略

- 使用 brand-surface 作为背景色
- 叠加 brand-primary 的渐变
- 显示居中图标或品牌首字母
- 加载完成后过渡替换

## 图片优化

- 使用 WebP 格式，PNG 备选
- 响应式 srcset 提供 2x 分辨率
- loading="lazy" (非 Hero)
- 预设宽高避免 CLS
