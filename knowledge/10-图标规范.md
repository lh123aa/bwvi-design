# 图标规范

## 图标尺寸

| 用途 | 尺寸 | 粗细 |
|:----|:----:|:----:|
| 导航栏图标 | 24px | 1.5px |
| 按钮图标 | 20px | 1.5px |
| 卡片图标 | 32px | 2px |
| 装饰图标 | 48-64px | 2px |
| 品牌 Logo | 32-128px | - |

## 风格一致性

- 同一页面使用同一图标风格 (outline / filled / duotone)
- 图标颜色使用品牌色或中性色
- 装饰图标使用 brand-accent 色
- 功能图标使用 brand-text 色

## SVG 最佳实践

- 使用 viewBox 而非固定宽高
- stroke-width 统一为 1.5 或 2
- 使用 currentColor 以便主题切换
- 保持最小 24x24 的点击区域
