# 动效原则

## 12 种动画类型

| 类型 | 触发方式 | 用途 |
|:----|:--------|:-----|
| fadeIn | 页面加载 | 淡入出现，适合图片和文本块 |
| slideUp | 滚动进入 | 从下方滑入，适合卡片列表 |
| slideIn | 滚动进入 | 从侧面滑入，适合侧边栏 |
| scale | 悬停/加载 | 缩放效果，适合按钮和卡片 |
| rotate | 悬停 | 旋转效果，适合图标和装饰元素 |
| bounce | 加载完成 | 弹跳效果，适合 CTA 按钮 |
| glow | 悬停 | 发光效果，适合科技感按钮 |
| typing | 加载 | 打字机效果，适合标题 |
| float | 持续 | 浮动效果，适合 Hero 装饰 |
| stagger | 滚动 | 交错出现，适合网格列表 |
| parallax | 滚动 | 视差滚动，适合 Hero 背景 |
| ripple | 点击 | 涟漪效果，适合按钮反馈 |

## 7 种缓动曲线

ease-out: 自然停下，适合 UI 元素进入
ease-in-out: 平滑过渡，适合页面切换
ease-in: 加速进入，适合退出动画
linear: 均匀运动，适合旋转和加载
spring: 弹性效果，适合弹跳反馈
bounce: 多次弹跳，适合趣味元素
smooth: 自定义贝塞尔，适合品牌定制
