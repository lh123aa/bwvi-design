# 导航模式

## 导航类型

| 类型 | 结构 | 适用 |
|:----|:-----|:-----|
| 顶栏导航 | 水平排列，Logo 在左，链接在右 | 大多数网站，通用性好 |
| 侧栏导航 | 垂直排列，可折叠 | Dashboard、后台管理 |
| 标签导航 | 水平标签，切换内容 | 设置页面、分类浏览 |
| 汉堡菜单 | 隐藏式，点击展开 | 移动端、极简设计 |
| 面包屑 | 层级路径 | 内容深、层级多的网站 |
| 页脚导航 | 底部链接组 | 辅助导航、法律信息 |

## 使用场景

- 信息架构层级 ≤ 2: 顶栏导航
- 信息架构层级 ≥ 3: 侧栏 + 面包屑
- 移动端优先: 汉堡菜单
- 内容类网站: 顶栏 + 页脚
- 工具类网站: 侧栏
