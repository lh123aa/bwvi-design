# 内容规则

## 内容层级

一级 (Hero / 主标题): 最多 12 个字，传递核心价值主张
二级 (副标题 / 段落标题): 最多 30 个字，支撑核心主张
三级 (正文 / 描述): 鼓励阅读，控制段落长度在 3-5 行

## CTA 位置规则

- Hero 区域必须包含 1 个主要 CTA
- 每个大段内容后跟一个次要 CTA
- 页面底部放置最终 CTA
- 单个页面 CTA 不超过 5 个

## 叙述流

1. 吸引注意 (Hero) → 2. 建立共鸣 (问题/痛点) → 3. 提供方案 (产品/服务) → 4. 证明价值 (案例/数据) → 5. 行动号召 (CTA)
