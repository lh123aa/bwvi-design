# 品牌协议

## 品牌色使用规则

1. Primary (主色): 占视觉面积 60%，用于背景、大标题、主导航
2. Secondary (辅色): 占 30%，用于卡片背景、次要元素、边框
3. Accent (强调色): 占 10%，用于 CTA 按钮、链接高亮、提醒标记
4. Surface (背景色): 页面和容器的背景色
5. Text (文本色): 正文内容颜色，必须与背景有充足对比

## 品牌一致性检查

| 检查项 | 要求 |
|:------|:-----|
| 主色与强调色对比度 | ≥ 3:1 (大文本 AA) |
| 文本与背景对比度 | ≥ 4.5:1 (AA) / ≥ 7:1 (AAA) |
| 颜色数量 | 不超过 5 种 (不含黑白灰) |
| 字体数量 | 不超过 2 种 (显示+正文) |
