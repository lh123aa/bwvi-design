# 数据可视化

## 图表类型选择

| 数据类型 | 推荐图表 | 说明 |
|:--------|:--------|:-----|
| 趋势 (时间序列) | 折线图 | 展示变化趋势，1-6 条线 |
| 对比 (类别) | 柱状图 / 条形图 | 横向对比，≤ 12 个类别 |
| 比例 (部分-整体) | 饼图 / 环形图 | ≤ 5 个部分，用环形更佳 |
| 关联 (两个变量) | 散点图 | 展示数据相关性 |
| 分布 (频率) | 直方图 | 数据分布形态 |
| 排名 | 条形图 (降序) | 清晰展示排序 |

## 颜色编码

- 使用 brand-primary 作为主色
- 渐变色使用 brand-secondary → brand-accent
- 语义色: 红 (负面)、绿 (正面)、黄 (警告)
- 确保色盲友好: 避免红绿并置，使用纹理辅助

## 数据笔墨比

数据笔墨比 = 数据相关墨水 / 总墨水。目标 ≥ 0.8。

- 移除网格线
- 简化坐标轴
- 减少装饰元素
- 数据标签明确
