# 组件规格

## 通用组件变体

| 组件 | 变体 | 间距 | 状态 |
|:----|:----|:----|:-----|
| Button (按钮) | primary / secondary / outline / ghost | 内边距 12px 24px | default / hover / active / disabled / loading |
| Card (卡片) | bordered / elevated / flat / interactive | 内边距 24px | default / hover / active |
| Input (输入框) | default / filled / outline | 内边距 12px 16px | default / focus / error / disabled |
| Modal (模态框) | default / fullscreen / drawer | 内边距 24px | open / closing / closed |

## 组件间距

- 组件组内间距: 16px
- 组件组间间距: 32px
- 块级组件间距: 64px
- 标题到关联组件间距: 24px
