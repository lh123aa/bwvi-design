📖 了解更多
BWVI 是什么？ ▼
BWVI 不是设计工具。它是 AI Agent 与设计执行之间的决策层。它不画像素——它确保每个像素都有理由。CLI + MCP Server，让 AI Agent 拥有结构化的设计决策能力。
与 Open-Design / Huashu-Design 的关系？ ▼
BWVI 是"决策层"——决定画什么的架构师。Open-Design 是执行引擎——能画任何东西的工厂。Huashu-Design 是工匠工作室——把一件事做到极致的匠人。三者可以串联使用。
如何开始使用？ ▼
只需一行命令：npx bwvi init my-project && npx bwvi generate "你的项目" --direct。零安装、零配置、零 daemon。
