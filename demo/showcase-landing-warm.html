warm-minimal BWVI

Usage

bwvi init [project-name]      Initialize a new design project
bwvi analyze <task>           Analyze a design task
bwvi generate <task>          Generate design output
bwvi critique <file>          Critique an HTML output file
bwvi --help                    Show this help

Examples

bwvi init my-landing
bwvi analyze "coffee brand landing page"
bwvi generate "coffee brand landing page" --direction=warm-minimal
bwvi critique output.html

Design Decisions

BWVI uses a structured decision protocol: direction → palette → typography → layout → detail. Each decision is persisted, auditable, and can be rolled back.
